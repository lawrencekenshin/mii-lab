Reading it. Open interest is the number of option contracts still open after each day. A stock ranks here when far more new contracts opened on one side (calls or puts) than the other, measured against that stock's own options, so a big name and a small one can sit on the same list. The time frames add up each day's new positions.

Opened is not the same as bought. Every option has a buyer and a seller. “Read” looks at where the last trades sat against the price quoted at the close: near the asking price usually means buyers were in a hurry, near the bid means sellers were. Calls sold at the bid are often stock owners writing calls, not a bet on a rise.

Timing. Open interest is posted the morning after each session, so the newest full day is always one session behind. The “traded but not settled” section uses the newest session's trading: where more contracts traded than were open that morning, the difference has to be new positions.
